# Grade 2 AI Literacy – Pixel's AI Training Academy

Interactive classroom presentation for **Lesson 1: Learning From Data and Patterns**.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
```

## Classroom use

- Designed for 16:9 projector / smartboard.
- Press **F** for fullscreen, **T** for Teacher Mode, arrows to change screens.
- Sound starts muted. Use the speaker button if you want quiet effects.
- Progress, scores, and the current screen save in the browser (`localStorage`).

Lesson photos live in `public/images/` and are listed in `src/data/assets.ts` so they can be replaced later.
